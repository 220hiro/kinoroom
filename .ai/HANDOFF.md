# Handoff

Updated: 2026-10-10

## Current goal

Создан и протестирован персональный онлайн-кинотеатр «КиноРум PRO» в стиле Лампы (Lampa), работающий «из коробки» без плагинов, развёрнутый на Vercel с автоматической защитой от рекламы и чистым торрент-стримингом.

## Done

- Настроен стек Next.js 16 + React 19 + TypeScript + Tailwind CSS v4.
- Интегрирован WebTorrent streaming engine:
  - Поддержка HTTP 206 Partial Content (Range requests) для плавной перемотки в браузере.
  - Поиск раздач на трекерах (Rutor) с определением качества (4K, 1080p, BDRip), сидов и размера.
  - Поддержка ввода magnet-ссылок, загрузки `.torrent` файлов и выбора файлов/серий внутри раздачи.
- Интегрирован мульти-серверный онлайн-плеер `OnlinePlayer` (VidLink, VidSrc, SmashyStream, 2Embed):
  - Добавлена аппаратная песочница браузера (`HTML5 Sandbox`) с блокировкой всплывающих окон, вкладок и top-navigation.
  - Добавлена политика `referrerPolicy="no-referrer"` против рекламного трекинга.
  - Добавлен переключатель анти-рекламы.
- Полноценная интеграция внешнего TorrServer (коммит `a15d5a5` + исправления безопасности):
  - Устранена уязвимость SSRF в `/api/torrent/torrserver`: блокировка RFC1918/приватных адресов, IPv6 link-local/ULA, облачных метаданных и отключение redirect-цепочек (`redirect: 'error'`).
  - Приоритетная фиксация на серверной переменной `TORRSERVER_URL`, исключающая манипуляцию целевым хостом со стороны клиента.
  - Проброс аутентификации (Basic credentials) в URL видеопотока для беспрепятственного воспроизведения в теге `<video>` и внешних плеерах.
  - Нативная поддержка GStreamer HLS (`/gst/{hash}/master.m3u8?index={id}`) для бесшовного транскодирования на iPhone / Safari с автоматическим fallback на прямой HTTP range поток.
  - Исправлен баг замыкания интервала статуса (`infoHashRef` + последовательный `setTimeout`), исключающий дублирование запросов `action: add`.
  - Добавлены ссылки на Outplayer, VLC и PotPlayer в меню внешнего плеера.
- Lampa-стиль UI:
  - Главная страница с HeroBanner и каруселями категорий («В тренде», «Популярные фильмы», «Сериалы», «Топ»).
  - Карточка фильма/сериала с постером, рейтингом, актёрами, сезонами/сериями и встроенным плеером.
  - Страница «Торрент-плеер» (`/torrent`) для прямого стриминга любых ссылок и файлов.
  - Библиотека закладок и история просмотров с сохранением прогресса по таймкоду.
  - Переключение профилей пользователей (для нескольких человек) и опциональная защита сайта паролем.
