# Подтверждённые уроки КАДР

- HTTP 200, успешный iframe, изменение currentTime и зелёная таблица сами по себе не доказывают воспроизведение. Проверять декодирование и реальный пользовательский путь.
- Названия озвучек и доступность субтитров берутся из метаданных выбранного файла; при неизвестных данных нельзя обещать дубляж или качество.
- При копировании видео и перекодировании аудио входная точная перемотка может обрабатывать их по-разному. Новый путь на холодном seek кодирует оба потока; реальная проверка синхрона на iPhone всё ещё нужна.
- Независимые зрители должны иметь независимые сессии. Старые запросы плейлиста не должны возвращать предыдущую озвучку.
- Субтитры в HTML родительской страницы не становятся автоматически субтитрами стороннего iframe или системного окна iOS.
- Графические PGS/VobSub нельзя объявлять текстовыми WebVTT без OCR/вжигания. Показывать реальное ограничение и разрешать SRT/VTT.
- CSS-растягивание не является системным fullscreen. В текущей версии пользователь выбрал обычный inline-просмотр на iPhone.
- Тесты в Chromium/WebKit на компьютере не подтверждают реальные Safari iOS, нагрев и автономность телефона.
- Ноутбук владельца не является сервером размещения. Публичные туннели и автоматические fallback на localhost удалены.
