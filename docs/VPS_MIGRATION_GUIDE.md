# КиноРум PRO — Полное руководство по миграции на VPS и настройке стриминга

## 1. Итоговый технический аудит: Почему проект не работал на Vercel

| Проблема | Поведение на Vercel | Решение на собственном VPS |
|---|---|---|
| **Лимит длительности Serverless** | Запросы принудительно обрываются через 15–60 секунд. Видеопоток не может непрерывно передаваться часами. | Непрерывный Node.js / Caddy демон без таймаутов на уровне соединения. |
| **Ограничение RAM и файловой системы** | Vercel Serverless имеет лимит 1024 МБ RAM и эфемерную файловую систему `/tmp`, которая очищается при ротации контейнеров. | Выделенный RAM-кэш TorrServer 500 МБ в оперативной памяти сервера без перезаписи SSD. |
| **P2P блокировка на Vercel** | WebTorrent не может открыть постоянные TCP/UDP сокеты для пиров внутри бессерверных лямбд AWS/Vercel. | Полноценный Docker-контейнер TorrServer (`tsdc/torrserver`) с открытым доступом к DHT и трекерам. |
| **Проблема CORS и Mixed Content** | Если Vercel открыт по `https://`, а TorrServer поднят по `http://IP:8090`, браузер блокирует запросы из-за Mixed Content и отсутствия SSL. | Caddy выступает единым обратным прокси: и сайт, и видеопотоки (`/stream`, `/gst`) идут с одного домена по доверенному SSL (`https://`). Никаких проблем с CORS. |
| **Несовместимость MKV / AC3 с iPhone Safari** | Safari нативно воспроизводит только MP4/H.264/AAC и HLS (.m3u8). Попытка открыть raw MKV с многоканальным звуком AC3/DTS приводила к ошибке `MEDIA_ERR_SRC_NOT_SUPPORTED`. | Автоматический выбор режима HLS (`/gst/...`) для iOS устройств + плеер на базе `hls.js` с ручным переключением аудиодорожек и субтитров. |
| **Рекламные окна сторонних балансеров** | Балансеры (Collaps, Kinobox) показывают кликандеры и всплывающую рекламу. | Плеер КиноРум на базе прямых торрент-потоков является приоритетным первичным источником (без рекламы). Балансеры переведены в статус вторичного резерва. |

## 3. Сетевая архитектура и безопасность (All-in-One Single Origin)

```
                            [ Клиент: iPhone / TV / PC ]
                                        │
                                        │ HTTPS (Порт 443)
                                        ▼
                   ┌─────────────────────────────────────────┐
                   │             Caddy Web Server            │
                   │        (Автоматический SSL Let's Encrypt)│
                   └────────────────────┬────────────────────┘
                                        │
                 ┌──────────────────────┴──────────────────────┐
                 │ Маршрутизация по путям (Внутри сети Docker) │
                 ▼                                             ▼
        [ / (Все страницы, API) ]                   [ /stream* и /gst* ]
                 │                                             │
                 ▼                                             ▼
     ┌───────────────────────┐                    ┌───────────────────────┐
     │      Next.js 16       │                    │    TorrServer v134    │
     │   (Standalone Node)   │ ◄── API статуса ── │     (GStreamer)       │
     │      Порт: 3000       │                    │      Порт: 8090       │
     └───────────────────────┘                    └───────────────────────┘
```

### Ключевые преимущества архитектуры:
- **Никаких портов наружу**: порт `8090` закрыт брандмауэром и доступен только внутри приватной сети `kinoroom_net`.
- **Единый домен**: клиент загружает страницу с `https://kinoroom.kz` и видеопоток с `https://kinoroom.kz/stream?link=...`. Браузер не блокирует запросы по CORS или Mixed-Content.
- **Мгновенный буфер**: директива Caddy `flush_interval -1` отключает промежуточную буферизацию прокси, отдавая чанки видео моментально.

## 4. Настройка DNS и Cloudflare

Если вы используете **Cloudflare** для управления доменом:
1. Добавьте `A`-запись:
   - **Type**: `A`
   - **Name**: `@` (или ваш поддомен, например `kino`)
   - **IPv4 address**: `IP_ВАШЕГО_СЕРВЕРА`
   - **Proxy status**: **DNS only** (Серый облачок ☁️, **НЕ оранжевый**).
   
> **ВАЖНО!** Не включайте оранжевое проксирование Cloudflare для видеопотоков торрентов:
> - Cloudflare ограничивает размер буфера и разрывает долгие соединения в бесплатном тарифе (Error 524 / 522).
> - Caddy сам выпускает и обновляет доверенный SSL-сертификат Let's Encrypt за 15 секунд.

Если у вас нет собственного домена:
Используйте бесплатный сервис динамического DNS, например **DuckDNS** (`ваш-логин.duckdns.org`), указав его в `.env`.

## 5. Пошаговая инструкция по развертыванию на VPS

### Шаг 1. Подключение к серверу по SSH
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

### Шаг 2. Клонирование репозитория
```bash
git clone https://github.com/220hiro/kinoroom.git /opt/kinoroom
cd /opt/kinoroom
```

### Шаг 3. Запуск скрипта автоматической установки
Скрипт сам настроит Swap (2 ГБ), установит Docker, настроит UFW и запустит контейнеры:
```bash
bash deploy.sh
```

В процессе скрипт запросит ваш домен (например, `kinoroom.kz`) и TMDB API ключ.

### Шаг 4. Проверка статуса
```bash
docker compose ps
docker compose logs -f caddy
```

## 6. Стратегия видеодвижка: Direct Remux против CPU Transcode

| Режим | Нагрузка на CPU | Поддержка устройств | Принцип работы |
|---|---|---|---|
| **Direct Remux (По умолчанию)** | < 10% (1 ядро) | ПК, Android, Smart TV | Поток видео H.264/HEVC передается без пересжатия видеочипа. Меняется только контейнер на лету. Позволяет смотреть до 4-х 1080p потоков одновременно даже на VPS за 4 000 ₸. |
| **GStreamer HLS (`/gst/...`)** | 40–80% (на поток) | iPhone, iPad, Apple TV | Нарезает поток на HLS-сегменты `.m3u8` со звуком AAC, совместимым с Safari. |
| **Внешний плеер (Outplayer / VLC)** | 0% на сервере | Все устройства | Сервер лишь отдает файл по HTTP, все декодирование выполняет мобильный процессор смартфона. |

## 8. Команды для обслуживания сервера

- **Просмотр логов в реальном времени:**
  ```bash
  docker compose logs -f kinoroom
  docker compose logs -f torrserver
  ```
- **Перезапуск контейнеров:**
  ```bash
  docker compose restart
  ```
- **Обновление до последней версии:**
  ```bash
  git pull
  docker compose up -d --build
  ```
- **Очистка временных данных торрентов:**
  ```bash
  docker compose exec torrserver rm -rf /torrserver/torrents/*
  ```
